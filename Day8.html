📊 Choosing the Right Visual Type

The Visual Selection Framework

Decision Tree: What should I use?

  • Showing Trends? ➔ Use a Line Chart.
  • Comparing Categories? ➔ Use a Clustered Bar Chart.
  • Part-to-Whole (few items)? ➔ Use a Donut Chart.
  • Part-to-Whole (many items)? ➔ Use a Treemap.
  • Seeing Relationships (2+ metrics)? ➔ Use a Scatter Chart.
  • Tracking a Goal? ➔ Use a Gauge or KPI Visual.

Visual Types by Purpose

📈 Comparison Visuals

Bar Chart (Clustered/Stacked)
📊

Best for: Comparing values across categories

When to use:

  • Compare sales by product
  • Compare regions or segments
  • Horizontal bars for long category names

Max categories: 10-15 for readability

Column Chart
📊

Best for: Comparing values over time periods

When to use:

  • Monthly/Quarterly comparisons
  • Year-over-year analysis
  • Vertical orientation preferred
Table & Matrix
📋

Best for: Detailed data lookup

When to use:

  • Display exact values
  • Multi-dimensional analysis
  • Drill-down hierarchies (Matrix)

📉 Trend Visuals

Line Chart
📈

Best for: Showing trends over time

When to use:

  • Continuous time series
  • Multiple trend lines comparison
  • Spotting patterns and anomalies

Add: Trend lines, forecasting

Area Chart
📊

Best for: Showing cumulative totals over time

When to use:

  • Emphasize magnitude of change
  • Stacked to show part-to-whole
  • Volume over time
Combo Chart
📊

Best for: Comparing different scales

When to use:

  • Revenue (bars) + Profit % (line)
  • Volume + Price trends
  • Different measurement units

🥧 Part-to-Whole Visuals

Pie Chart
🥧

Best for: Simple proportions (2-5 slices)

When to use:

  • Market share breakdown
  • Budget allocation
  • Limited categories only!

⚠️ Limit: Max 5 slices

Donut Chart
🍩

Best for: Same as Pie, with center space

When to use:

  • Display total in center
  • Slightly more modern look
  • 2-5 categories
Treemap
🗺️

Best for: Hierarchical part-to-whole

When to use:

  • Many categories (6-20)
  • Nested hierarchies
  • Product portfolio analysis
100% Stacked Bar/Column
📊

Best for: Comparing proportions across groups

When to use:

  • Category composition over time
  • Relative percentages
  • Distribution comparison

🗺️ Geographic Visuals

Map (Azure Maps)
🌍

Best for: Geographic distribution

When to use:

  • Sales by region/country
  • Store locations
  • Bubble size = metric value

Requires: Location data (City, Country, Lat/Long)

Filled Map
🗺️

Best for: Choropleth maps

When to use:

  • State/Country-level metrics
  • Heat map effect
  • Regional comparisons

📊 KPI & Metrics Visuals

Card
🏷️

Best for: Single important number

When to use:

  • Total Revenue
  • Customer Count
  • Any single KPI
Multi-row Card
🏷️🏷️

Best for: Multiple related metrics

When to use:

  • Customer dashboard (Name, Revenue, Orders)
  • Product details
  • Grouped KPIs
KPI Visual
🎯

Best for: Goal tracking

When to use:

  • Actual vs Target
  • Progress indicators
  • Trend direction

Shows: Value, Target, Trend

Gauge
⏲️

Best for: Progress toward goal

When to use:

  • % of quota achieved
  • Capacity utilization
  • Single metric with target

Visuals to Avoid (Usually)

⚠️ Use Sparingly:

  • 3D Charts: Distort perception, hard to read exact values
  • Pie with many slices: Hard to compare, use bar chart instead
  • Dual-axis with misleading scales: Can be manipulative
  • Radar/Spider charts: Difficult to interpret accurately

Visual Selection Cheat Sheet

Your Goal Recommended Visual Alternative
Compare categories Bar/Column Chart Table
Show trend over time Line Chart Area Chart
Part of a whole Treemap (many) or Donut (few) 100% Stacked Bar
Geographic distribution Map Bar Chart by Region
Single KPI Card Gauge (with target)
Actual vs Target KPI Visual Gauge or Bullet Chart
Detailed lookup Table or Matrix N/A
Hierarchical drill-down Matrix Treemap

🎨 Report Formatting & Styling

Accessing Format Options

Three ways to format:

  1. Visual Format Pane: Select visual → Format icon (paint roller) → Customize
  2. Report Format Pane: Click canvas → Format icon → Page settings
  3. Themes: View → Themes → Choose or customize

Visual Formatting Options

General Settings

  • Title: On/Off, Text, Font, Color, Background
  • Effects: Background color, Border, Shadow, Glow
  • Tooltips: Default or Report page
  • Position: X, Y, Width, Height

Data Colors

  • Default colors: Single color for all
  • Show all: Different color per category
  • Conditional formatting: Color by value
  • Custom colors: Brand colors

Data Labels

  • Toggle: Show/Hide values on chart
  • Position: Inside, Outside, Auto
  • Format: Font, Size, Color
  • Units: Display units (K, M, B)

Axis Settings

  • Range: Auto or Manual min/max
  • Scale: Linear or Logarithmic
  • Labels: Font, Color, Rotation
  • Gridlines: Show/Hide, Style

Legend

  • Position: Top, Bottom, Left, Right
  • Title: Custom text
  • Font: Size and Color
  • Show/Hide: Toggle visibility

Background & Border

  • Color: Solid or Gradient
  • Transparency: 0-100%
  • Border: Color, Width, Radius
  • Effects: Shadow, Glow

Conditional Formatting

Where to Apply:

  • Table/Matrix: Background colors, Font colors, Data bars, Icons
  • Cards: Background based on value
  • Charts: Data colors based on value

How to Apply:

  1. Select visual
  2. Format pane → Find relevant section (e.g., Cell elements for Matrix)
  3. Click fx icon next to color option
  4. Choose:
    • Rules: If value > X then color Y
    • Gradient: Low to High color scale
    • Field value: Color based on another column

Example: Traffic Light Colors

-- For Profit Margin Red: Values < 10% Yellow: Values 10-20% Green: Values > 20%

Report Themes

Themes: Pre-defined color schemes and fonts applied to entire report

How to use:

  1. View tab → Themes → Choose built-in theme
  2. Or customize: View → Themes → Customize current theme
  3. Or import: Browse for theme → Upload JSON file

What themes control:

  • Primary colors (8-10 colors)
  • Font family and sizes
  • Background colors
  • Visual defaults

Design Best Practices

✅ DO's

  • Use consistent colors (brand colors)
  • Limit to 3-4 main colors
  • Align visuals to grid
  • Use white space effectively
  • Make titles descriptive
  • Keep font sizes readable (min 10pt)
  • Remove chart junk (unnecessary elements)
  • Test on different screen sizes

❌ DON'Ts

  • Don't use too many colors
  • Don't make visuals too small
  • Don't use 3D effects
  • Don't overcrowd pages
  • Don't use clashing colors
  • Don't forget accessibility (color blind)
  • Don't ignore alignment

🚨 Common Design Mistakes to Avoid

  • The "Skittles" Effect: Using too many colors that don't have meaning. Stick to your theme.
  • Lack of Hierarchy: Making all visuals the same size. Your most important KPI should be 2x larger than other charts.
  • Clutter: Not using enough white space (margins). Let your data breathe!
  • Unsorted Data: Bar charts should almost always be sorted (Highest to Lowest).
  • Default Titles: "Sales by Category and Region" is boring. Use "Which Category drives the most Profit?"

Page Formatting

📄

Page-Level Settings

Access: Click canvas → Format pane

  • Canvas background: Color, Image, Transparency
  • Page size: 16:9, 4:3, Letter, Custom
  • Wallpaper: Background image
  • Page information: Name, Description

🔗 Visual Interactions & Filtering

Understanding Visual Interactions

By default: When you click on a visual, it filters or highlights other visuals on the same page

Three interaction types:

  • Filter: Selected visual filters the target visual (most common)
  • Highlight: Shows selected portion highlighted, dimming the rest
  • None: No interaction occurs

Editing Interactions

🎛️

How to Edit Interactions

  1. Select the SOURCE visual (the one that will do the filtering)
  2. Go to Format tab → Edit interactions
  3. Icons appear above each target visual:
    • 🔍 Filter icon
    • 🎯 Highlight icon
    • ⊘ None icon
  4. Click desired interaction type for each target
  5. Click Edit interactions again to finish

Common Scenario: KPI Cards

You usually DON'T want other visuals to filter your KPI cards showing totals

Solution:

  1. Select slicer or chart
  2. Edit interactions
  3. Set KPI cards to "None"

Filter Types in Power BI

Visual-level Filters

Scope: Single visual only

Use: Limit data shown in one visual

Example: Show only Top 10 products

Page-level Filters

Scope: All visuals on current page

Use: Filter entire page context

Example: Show only Current Year data

Report-level Filters

Scope: All pages in report

Use: Global filters

Example: Exclude test data

Slicers

Scope: Visible to users

Use: Interactive filtering

Example: Date range, Category selection

Drill-Through Pages

Drill-through: Navigate from summary to detailed page, maintaining context

How it works:

  1. Create a detail page (e.g., "Product Details")
  2. Add field(s) to Drill-through wells (e.g., ProductName)
  3. Add detailed visuals
  4. On summary page: Right-click data point → Drill through → Product Details
  5. Detail page opens with context filtered
🔍

Creating Drill-Through

  1. Create new page: "Product Detail"
  2. In Filters pane → Drill through section
  3. Drag ProductName to drill-through field
  4. Add visuals showing product details
  5. Power BI automatically adds back button
  6. Test: Go to summary → Right-click product → Drill through

Cross-Filtering vs Cross-Highlighting

Aspect Cross-Filtering Cross-Highlighting
Behavior Hides non-matching data Dims non-matching data
Use When Want to see only relevant data Want to compare selected vs total
Visual Impact Data disappears Data stays but grayed out
Best For Detailed analysis Seeing proportions

⚡ Advanced Report Features

Bookmarks for Navigation

Bookmarks: Capture the current state of a report page (filters, visual visibility, selection)

Use cases:

  • Create navigation between pages
  • Show/hide visuals dynamically
  • Tell a data story
  • Create multiple views of same page
🔖

Creating Bookmarks

  1. View tab → Bookmarks Pane
  2. Set up your page (filters, selections, visible visuals)
  3. Click Add in Bookmarks pane
  4. Rename bookmark (e.g., "Sales View")
  5. Create more bookmarks with different states
  6. Test: Click bookmark names to switch views

Advanced: Link to Buttons

  1. Insert → Button → Blank or icon
  2. Select button → Format → Action → On
  3. Type: Bookmark
  4. Bookmark: Choose your bookmark
  5. Test in Reading View

Selection Pane

Selection Pane: Manage visual visibility and layering

Access: View → Selection Pane

Features:

  • Show/Hide: Eye icon to toggle visibility
  • Layer order: Drag to reorder (top = front)
  • Group: Group related visuals
  • Rename: Give visuals meaningful names

Tooltips (Custom Report Pages)

Tooltip pages: Show additional context on hover without leaving main page

How to create:

  1. Create new page
  2. Format → Page information → Type: Tooltip
  3. Set page size (Canvas settings → Type: Tooltip)
  4. Add visuals (they'll show on hover)
  5. On main page: Select visual → Format → Tooltips → Report page
  6. Choose your tooltip page

Mobile Layout

📱

Optimizing for Mobile

  1. View tab → Mobile layout
  2. Canvas changes to phone dimensions
  3. Drag visuals from right pane to phone canvas
  4. Resize and reposition for mobile
  5. Not all visuals need to be included
  6. Prioritize most important KPIs

💡 Tip: Design mobile-first for executive dashboards

Buttons & Navigation

Button Types

  • Blank: Custom text/icon
  • Back: Return to previous page
  • Bookmark: Navigate to bookmark
  • Drill through: Go to detail page
  • Page navigation: Go to specific page
  • Q&A: Open Q&A interface
  • Web URL: External link

Button States

  • Default: Normal appearance
  • On hover: Mouse over effect
  • On press: Click effect
  • Each state can have different formatting

Custom Visuals from AppSource

AppSource: Marketplace for additional visuals beyond built-in ones

How to add:

  1. Visualizations pane → "..." → Get more visuals
  2. Browse or search AppSource
  3. Click visual → Add
  4. Visual appears in Visualizations pane

Popular custom visuals:

  • Chiclet Slicer: Better slicer with images
  • Text Filter: Search box filter
  • Bullet Chart: Compare actual to target
  • Timeline Slicer: Date range with slider
  • Word Cloud: Text frequency visualization
  • Sankey Diagram: Flow visualization
⚠️ Custom Visual Cautions:
  • Not all are created by Microsoft (review publisher)
  • May have performance implications
  • Some require special licensing
  • Test thoroughly before deploying

🧮 Phase 0: Data Preparation (Measures & Columns)

Before building the visuals, we need to create the underlying logic. Follow these steps to set up your Data Model.

C

Step 1: Calculated Columns

Calculated columns are pre-computed and stored in your data. We'll create one to categorize profit levels.

  1. Go to the Data View (left sidebar).
  2. Select the day8_practice_dataset table.
  3. Click New Column in the top ribbon.
  4. Enter the following DAX:
Profitability Status = 
IF(
    [Profit] > 100, 
    "High Profit", 
    IF([Profit] > 0, "Profitable", "Loss")
)
M

Step 2: Core Measures

Measures are dynamic and calculated on the fly based on your filters.

  1. Go to the Report View.
  2. Right-click the table name ➔ New Measure.
  3. Create the following essential measures:
1. Total Revenue
Total Revenue = SUM(day8_practice_dataset[Sales])
2. Total Profit
Total Profit = SUM(day8_practice_dataset[Profit])
3. Profit Margin %
Profit Margin % = DIVIDE([Total Profit], [Total Revenue], 0)

*Note: Select this measure and click the % icon in the ribbon to format it.

T

Step 3: Time Intelligence Measures

To compare performance over time (Day 8 focus), create these advanced measures:

1. YTD Revenue (Year-to-Date)
YTD Revenue = TOTALYTD([Total Revenue], 'day8_practice_dataset'[OrderDate])
2. Prior Year Sales (Last Year)
Sales LY = CALCULATE([Total Revenue], SAMEPERIODLASTYEAR('day8_practice_dataset'[OrderDate]))
3. YoY Sales Growth % (Year-over-Year)
YoY Sales Growth % = 
DIVIDE(
    [Total Revenue] - [Sales LY], 
    [Sales LY], 
    0
)
H

Step 4: Creating Hierarchies

Hierarchies allow users to "Drill Down" (explore deeper levels) within a single visual.

  1. Go to the Data Pane (right side).
  2. Geography Hierarchy:
    • Right-click Region ➔ Create hierarchy.
    • Right-click Country ➔ Add to hierarchy ➔ Region Hierarchy.
    • Repeat for State and then City.
    • Rename it to Geography Hierarchy.
  3. Product Hierarchy:
    • Right-click Category ➔ Create hierarchy.
    • Add SubCategory and then ProductName.
    • Rename it to Product Catalog.

Exercise 1: Executive Summary Page (30 minutes)

1

Create KPI Dashboard

  1. Setup: Create a new page named "Executive Summary". Go to View > Themes and select "Executive" or "Innovation".
  2. KPI Header: At the very top, add four Card visuals:
    • Total Revenue: Use the [Total Revenue] measure.
    • YTD Sales: Use the [YTD Revenue] measure.
    • YoY Growth: Use the [YoY Sales Growth %] measure.
    • Profit Margin: Use the [Profit Margin %] measure.
  3. Trends: Add a Line Chart.
    • Axis: OrderDate (Year and Month)
    • Values: [Total Revenue]
    • Tip: Enable "Data Labels" in the Format pane for immediate clarity.
  4. Regional Performance: Add an Azure Map or Filled Map.
    • Location: Geography Hierarchy (to enable Region-to-City drill-down)
    • Bubble Size/Color: [Total Revenue]
  5. Product Breakdown: Add a Treemap.
    • Group: Product Catalog (to enable Category-to-Product drill-down)
    • Values: [Total Revenue]
  6. Alignment: Use Format > Align to ensure all visuals are perfectly spaced. Turn on "Snap to Grid" in View tab.

Exercise 2: Product Analysis Page (20 minutes)

2

Detailed Product View

  1. The Matrix: Create a page "Product Analysis". Add a Matrix visual.
    • Rows: Category, then SubCategory (to enable drill-down).
    • Columns: Segment
    • Values: [Total Revenue] and [Profit Margin %].
    • Drill-down: Click the "Down Arrow" icon in the visual header to explore SubCategories.
  2. Conditional Formatting:
    • Go to Format pane > Cell elements.
    • Turn on Background color for Profit Margin %.
    • Click fx: Set "Lowest value" to Red and "Highest value" to Green.
  3. Top Performers: Add a Clustered Bar Chart.
    • Y-Axis: ProductName
    • X-Axis: [Total Revenue]
    • Filters: In the Filter pane, set Product to "Top N", N=10, by [Total Revenue].

Exercise 3: Configure Interactions (15 minutes)

3

Set Up Filtering Behavior

  1. Go to Executive Summary page
  2. Select Year slicer
  3. Format → Edit interactions
  4. Set KPI cards to "None" (don't filter totals)
  5. Keep other visuals as "Filter"
  6. Select Treemap
  7. Edit interactions → Set Map to "Highlight"
  8. Test interactions

Exercise 4: Create Drill-Through

4

Product Detail Page

  1. Detail Page: Create a new page named "Product Detail".
  2. Target Field: In the Filters pane, look for the Drill-through section. Drag ProductName into the "Add drill-through fields here" well.
  3. Content: Add a large Card for ProductName. Add a Line Chart for the [Total Profit] measure over OrderDate.
  4. Navigation: Power BI will automatically create a "Back" button. Format it to be visible (e.g., increase size, change color).
  5. Test: Go back to "Product Analysis", right-click a product in the Matrix, select Drill through > Product Detail.

Exercise 5: Add Bookmarks (10 minutes)

5

Create View States

  1. Open Panes: Go to View tab and enable Bookmarks and Selection panes.
  2. State 1 (Sales View): Set your slicers to show only "Technology". Click Add in the Bookmarks pane and rename it to "Tech Focus".
  3. State 2 (Full View): Clear all filters. Click Add and rename to "Global View".
  4. Button Logic:
    • Insert a Button > Blank. In the Format > Action section:
    • Type: Bookmark
    • Bookmark: Tech Focus
    • Repeat for the "Global View" button.
  5. Navigation Bar: Place these buttons in a row at the top of your report to act as a navigation menu.
