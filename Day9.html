💬 Q&A Visual - Natural Language Queries

What is Q&A Visual?

Q&A Visual: Allows users to ask questions about data in natural language and get visual answers automatically.

How it works:

  1. User types a question (e.g., "total sales by region")
  2. Power BI interprets the question
  3. Creates appropriate visualization
  4. User can refine or ask follow-up questions

Benefits:

  • Enables self-service analytics for non-technical users
  • Reduces need for pre-built visuals
  • Accelerates data exploration
  • Natural, conversational interface

Adding Q&A Visual

1

How to Add Q&A

  1. Go to Report View
  2. Insert tab → Q&A button
  3. Q&A visual appears with question box
  4. Resize to fit your layout
  5. Users can now type questions

Example Questions

Sample Questions Users Can Ask:

"total sales by category"

→ Creates bar chart

"show revenue over time"

→ Creates line chart

"top 5 products by revenue"

→ Creates sorted bar chart

"average order value"

→ Creates card with number

"sales by region as map"

→ Creates filled map

"what drove sales increase"

→ Analyzes key factors

Teaching Q&A to Understand Your Data

Q&A Setup (Power BI Service Only):

  1. Publish report to Power BI Service
  2. Open in service → Q&A Setup
  3. Add synonyms (e.g., "revenue" = "sales")
  4. Define suggested questions
  5. Review and train on user questions

Best Practices:

  • Use clear, descriptive field names
  • Add synonyms for common terms
  • Create suggested questions for guidance
  • Test with actual user questions

Converting Q&A to Standard Visual

💡

Save Q&A Results

If a user asks a good question:

  1. After Q&A creates visualization
  2. Click "Turn this Q&A result into a standard visual"
  3. Visual becomes permanent on the page
  4. Can be formatted like any other visual
💡 Pro Tip: Place Q&A visual on a dedicated "Explore" page for ad-hoc analysis!

🎯 Key Influencers Visual

What is Key Influencers?

Key Influencers: AI-powered visual that analyzes what factors influence a metric to increase or decrease.

Use cases:

  • What drives customer churn?
  • What influences high sales?
  • What factors affect satisfaction scores?
  • What drives product returns?

Two tabs:

  • Key Influencers: Shows top factors influencing the metric
  • Top Segments: Shows groups with highest/lowest values

Step-by-Step Example: Customer Churn Analysis

2

Analyzing What Drives Customer Churn

Scenario: We have a dataset of customer feedback, subscription types, and support tickets. We want to find out what factors influence a customer to Churn (leave the service).

  1. Get Data: Download the CSV file above and load it into Power BI (Home > Get Data > Text/CSV).
  2. Insert Visual: Click on the Key Influencers icon in the Visualizations pane (it looks like a magnifying glass over a chart).
  3. Configure Fields:
    • Analyze: Drag the Churn field here. This is the metric we want to understand.
    • Explain by: Drag potential factors here: Rating, Support_Tickets, Subscription_Type, Tenure_Months, and Region.
  4. Set the Target: In the visual itself, there is a dropdown "What influences Churn to be". Select Yes.
  5. Review Results: Power BI's AI will automatically analyze the dataset and present the top factors driving Churn!

Reading the Results

1. Key Influencers Tab (Individual Factors)

The visual shows statements based on correlation and probability. For our dataset, you might see:

  • "When Support_Tickets is more than 4, the likelihood of Churn being Yes increases by 3.5x."
  • "When Subscription_Type is Basic, the likelihood of Churn being Yes increases by 2.8x."
  • "When Rating is less than 3, the likelihood of Churn being Yes increases by 2.5x."

*Clicking on each bubble shows a detailed chart comparing the influenced segment with the average.

2. Top Segments Tab (Combined Factors)

This tab finds combinations of factors (segments) that have the highest percentage of Churn.

  • Segment 1: Support_Tickets > 4 AND Subscription_Type is Basic. (Result: 100% Churn rate in this segment)
  • Segment 2: Rating < 3 AND Tenure_Months < 6.

Best Practices

✅ DO's

  • Use with sufficient data (100+ rows minimum)
  • Include diverse potential influencers
  • Analyze meaningful metrics
  • Consider correlation vs causation

❌ DON'Ts

  • Don't use with very small datasets
  • Don't assume causation from correlation
  • Don't ignore domain knowledge
  • Don't over-interpret results
⚠️ Remember: Key Influencers shows correlation, not necessarily causation. Always apply business knowledge when interpreting results!

🌳 Decomposition Tree Visual

What is Decomposition Tree?

Decomposition Tree: AI-powered visual for ad-hoc hierarchical exploration of data.

Key features:

  • Start with a metric (e.g., Total Sales)
  • Drill down by any dimension
  • AI suggests best splits
  • Interactive exploration
  • Find high/low contributors quickly

Use cases:

  • Root cause analysis
  • Finding outliers
  • Exploratory data analysis
  • Multi-dimensional drill-down

Step-by-Step Example: Sales Breakdown Analysis

3

Analyzing Sales Across Dimensions

Scenario: We want to break down our Total Sales to see which Categories, Sub-Categories, Regions, and Sales Reps are driving the most revenue.

  1. Get Data: Download the CSV file above and load it into Power BI (Home > Get Data > Text/CSV).
  2. Insert Visual: Click on the Decomposition Tree icon in the Visualizations pane.
  3. Configure Fields:
    • Analyze: Drag Sales_Amount here (ensure it is set to Sum).
    • Explain by: Drag Category, Sub_Category, Region, and Sales_Rep into this well.
  4. Start Exploring: The visual will start with a single bar showing Total Sales_Amount. Click the small "+" icon next to the bar to drill down!

Using the Decomposition Tree

Interactive Exploration:

Level 0: Total Sales Amount: $22,500 (approx)

↓ Click "+" → Choose High value

Level 1: AI splits by Category and shows Electronics is highest

  • Electronics: $11,500
  • Furniture: $6,000
  • Clothing: $5,000

↓ Click "+" on Electronics → Choose High value

Level 2: AI splits by Sub_Category

  • Laptops: $7,600
  • Phones: $3,900

AI-Powered Features

High Value & Low Value Splits:

When you click "+", you get three options:

  • Manual split: Choose the exact dimension you want to drill into (e.g., Region).
  • High value: A lightbulb icon. The AI automatically finds the dimension path that leads to the highest value of your metric.
  • Low value: A lightbulb icon. The AI finds the path that leads to the lowest value.

Why it's powerful: If you have 20 different dimensions in the "Explain by" well, clicking "High value" saves you from guessing which dimension has the biggest impact!

Decomposition Tree vs Matrix

Feature Decomposition Tree Matrix
Structure Flexible, user-driven Fixed hierarchy
Exploration Ad-hoc, any path Pre-defined drill-down
AI Assistance Yes (High/Low value) No
Best For Root cause analysis, exploration Systematic reporting

🐍 Python Visual - Custom Visualizations

What is a Python Visual?

Python Visual: Allows you to use Python scripts and libraries (like Matplotlib, Seaborn) to create custom visuals directly inside Power BI.

Why use Python Visuals?

  • Create highly customized charts not available in native Power BI
  • Use advanced statistical plotting
  • Leverage popular Python libraries (e.g., pandas, matplotlib, seaborn)
  • Perform data transformations before plotting

Prerequisites:

  • Python installed on your machine (e.g., Anaconda or standard Python)
  • Python integration configured in Power BI (File > Options and settings > Options > Python scripting)
  • Required libraries installed (pip install pandas matplotlib seaborn)

Step-by-Step Example: Sales vs. Marketing Scatter Plot

🐍

Creating a Scatter Plot with Trendline

Scenario: We will use a simple dataset to see how Marketing Spend affects Sales by plotting a scatter chart with a regression line using Seaborn.

  1. Get Data: Download the CSV file above and load it into Power BI (Home > Get Data > Text/CSV).
  2. Add the Visual: Click on the Py (Python visual) icon in the Visualizations pane.
  3. Enable Scripting: If prompted, click "Enable" to allow script execution.
  4. Add Data Fields: Drag Marketing_Spend and Sales into the "Values" well of the visual.
  5. Write the Script: In the Python script editor that appears at the bottom, write the following code:
import matplotlib.pyplot as plt import seaborn as sns # dataset is automatically provided by Power BI containing the fields you added # Drop any missing values to ensure accurate plotting df = dataset.dropna() # Set up the matplotlib figure size plt.figure(figsize=(10, 6)) # Draw the scatter plot with a regression trendline sns.regplot(data=df, x='Marketing_Spend', y='Sales', color='purple', scatter_kws={'s': 100}) # Add titles and labels plt.title('Impact of Marketing Spend on Sales', fontsize=16, color='#1e3c72') plt.xlabel('Marketing Spend ($)', fontsize=12) plt.ylabel('Sales ($)', fontsize=12) # Display the plot plt.grid(True, linestyle='--', alpha=0.6) plt.show()
  1. Run Script: Click the "Run script" icon (the play button) in the title bar of the script editor.
  2. View Result: A beautiful scatter plot showing the correlation between Marketing Spend and Sales with a trendline will render in your report!

Best Practices

✅ DO's

  • Ensure the Python script path is correctly set in Options
  • Always handle missing data (dropna() or fillna()) in your script
  • Use standard libraries like matplotlib and seaborn
  • Keep the dataset size reasonable to maintain visual performance

❌ DON'Ts

  • Don't use interactive Python libraries (like Plotly or Bokeh) as they are not fully supported
  • Don't perform heavy machine learning operations inside the visual script (do that in Power Query)
  • Don't forget to install required packages in your local Python environment
⚠️ Note: The dataset variable is automatically created by Power BI as a pandas DataFrame containing the fields you drag into the visual.

🌐 Publishing to Power BI Service

Power BI Desktop vs Power BI Service

Feature Power BI Desktop Power BI Service
Platform Windows application Cloud web service
Purpose Create & develop reports Share & collaborate
Data Modeling Full capabilities Limited
Report Design Full capabilities View & light editing
Sharing Share .pbix file Share links, embed
Data Refresh Manual Scheduled automatic
Collaboration Limited Full (workspaces, apps)

Publishing Process

📤

How to Publish

  1. In Power BI Desktop, ensure you're signed in
    • Top right → Sign in with work/school account
  2. Save your .pbix file
  3. Click Home → Publish
  4. Choose destination workspace:
    • My Workspace (personal)
    • Shared workspace (team)
  5. Click Select
  6. Wait for publishing to complete
  7. Click link to open in Power BI Service

Power BI Service Overview

URL: app.powerbi.com

Main Components:

  • Workspaces: Containers for reports, dashboards, datasets
  • Reports: Interactive multi-page reports
  • Dashboards: Single-page pinned visuals from reports
  • Datasets: Data models
  • Dataflows: Reusable data prep
  • Apps: Published collections for distribution

Sharing Reports

Method 1: Share Link

How: Report → Share → Copy link

Who: Anyone with link (if allowed)

Permissions: Read-only or can reshare

Best for: Quick sharing

Method 2: Email

How: File → Share → Email

Who: Specific people

Features: Can include snapshot

Best for: Scheduled distributions

Method 3: Publish to Web

How: File → Embed → Publish to web

Who: Public, anyone on internet

Warning: Data becomes public!

Best for: Public dashboards

Method 4: App

How: Create app from workspace

Who: Specific users/groups

Features: Professional distribution

Best for: Enterprise deployment

Data Refresh

Setting Up Scheduled Refresh:

  1. In Power BI Service, go to workspace
  2. Find dataset → More options (...) → Settings
  3. Expand Scheduled refresh
  4. Configure:
    • Refresh frequency (Daily, Weekly)
    • Time slots
    • Time zone
    • Email notifications on failure
  5. Apply

Requirements:

  • Data gateway for on-premises data
  • Pro or Premium license
  • Valid credentials configured
⚠️ Licensing Note: Free license allows publishing but limited sharing. Pro/Premium required for full collaboration features.
